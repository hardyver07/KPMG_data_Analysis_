# KPMG_data_Analysis_
🗂 Overview
This project simulates a real-world consulting scenario where KPMG seeks to improve lead conversions through customer segmentation and data cleaning. Using Excel and its advanced features, I analyzed over 10,000 customer records to uncover key trends and actionable insights.
## 🛠 Tools & Technologies
- Microsoft Excel
- Power Query
- Power Pivot
- Pivot Tables
- Macros
## 📊 Objectives
- Clean and standardize raw customer data
- Segment customers based on wealth, gender, and industry
- Identify high-value leads and conversion opportunities
- Enable reliable trend analysis and reporting
## 🔍 Methodology
- Data Cleaning
- Removed duplicates and nulls
- Standardized formats using Power Query
- Validated data types and corrected inconsistencies
- Segmentation Analysis
- Grouped customers by wealth bands, gender, and industry
- Used Pivot Tables to visualize segment distribution
- Applied filters and slicers for dynamic exploration
- Trend Identification
- Analyzed conversion rates across segments
- Highlighted top-performing industries and demographics
- Created dashboards for stakeholder reporting
## ✅ Results
- Improved data accuracy.
- Identified three key customer segments.
- Delivered a clean, interactive Excel workbook ready for business use
